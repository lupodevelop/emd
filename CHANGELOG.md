# Changelog

## [0.1.0]

### Added

- The emd language: eight Unicode dashes, paired instructions, a stack machine
  and a strict UTF-8 decoder.
- Readable assembly, a virtual machine, static analysis and a native C backend.
- Command-line tools for inspection, Unicode diagnostics, profiling, reduction
  and debugging with backward execution.
- A Neovim Studio and an interactive WebAssembly playground.
- Lean and Rocq formalizations, executable comparisons and documented
  implementation verification with explicit limits.
- A paper on the language and its verification.
- A separate case study of code generation through model CLIs, with raw results
  and benchmark analysis.

### Distribution

- Prebuilt CLI packages for Linux x86-64, macOS Apple Silicon and Intel,
  and Windows x86-64, including examples, documentation and the Neovim plugin.
- SHA-256 checksums for release packages.

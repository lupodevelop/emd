# Earlier runs

Kept as they were, so that nothing about the experiment's history is hidden. The current scripts do not rebuild them: the scorer changed along with the language.

- `pilot-0`: the first trial, 10 tasks per model.
- `v2`: 1323 answers on a version of the language with 29 instructions and no line limit, scored after breaking answers into lines. `summary.md` has its results, and `tasks.jsonl` and `system-prompt.md` are what the models saw.
